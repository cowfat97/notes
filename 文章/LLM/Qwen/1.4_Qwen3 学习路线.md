# Qwen3 学习路线

从「学到哪」到「动手做什么」：Qwen3 的完整学习内容、建议顺序、部署选型。动手实验见文末索引。

## 1 学习内容

1. **推理基础**（Mac 16GB 现在就能做）：采样参数实验、思考开关对比、system 提示词、多轮对话
2. **Tokenizer 原理**：BPE 分词、token id、聊天模板怎么拼
3. **API 调用**：百炼 / Qwen 官方 API，有 key 就能练
4. **Agent / 工具调用**：function calling（Qwen3 强化过 Agent 能力）
5. **微调**（台式机 5060 Ti 16G）：LoRA / QLoRA 微调 8B，SFT 数据构造
6. **部署服务化**（台式机）：vLLM / SGLang 起 OpenAI 兼容接口；量化 GGUF / AWQ / GPTQ
7. **架构原理**：思考/非思考双模式、MoE（30B-A3B：总 30B 只激活 3B）、256k 上下文（Qwen3-Next）
8. **多模态**：Qwen3-VL 看图理解

## 2 建议顺序

① Mac 上改采样参数 + 思考开关 + 多轮对话 → ② 学 tokenizer / 模板原理 → ③ 台式机 vLLM 部署 8B → ④ LoRA 微调 → ⑤ Agent 工具调用。

## 3 部署选型：vLLM vs Ollama

| | vLLM | Ollama |
| --- | --- | --- |
| 定位 | 高性能推理服务（吞吐优先） | 本地跑模型（易用优先） |
| 并发 | PagedAttention + continuous batching，多用户强 | 单用户够用，高并发弱 |
| 上手 | Python 包 / 容器，少量配置 | `ollama run` 一条命令 |
| 量化 | AWQ / GPTQ / FP8 | 主打 GGUF |
| OpenAI 兼容 API | 原生 | 支持 |

生产主流三家：vLLM / SGLang / TensorRT-LLM。Ollama 定位个人本地工具，生产少见。学习优先级：先学 vLLM（生产技能），Ollama 当玩具顺手玩。

Qwen3 全家族（0.6B / 1.7B / 4B / 8B / 14B / 32B / 30B-A3B / 235B-A22B）均为 apache-2.0 开源。
