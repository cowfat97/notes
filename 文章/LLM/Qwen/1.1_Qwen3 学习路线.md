# Qwen3 学习路线

从「学到哪」到「动手做什么」：Qwen3 的完整学习内容、建议顺序、部署选型。动手实验见文末索引。

## 1 全景：一个模型的一生

```text
预训练（厂商）→ 基座模型 → 后训练 SFT+RL（厂商）→ 指令版
→ 企业微调（领域数据 SFT/LoRA）→ 评测 → 部署（vLLM）→ 推理 → Agent 编排
```

- **基座模型**：只会续写不会对话——预训练只教「预测下一个词」
- **指令版**：厂商继续训练两阶段——SFT 教格式、RL 教质量（思考模式就是 RL 训出来的）。HF 上 Qwen/Qwen3-1.7B 是指令版（基座带 -Base 后缀）
- **微调**是动作不是模型：厂商后训练与企业微调是同款动作（在已有模型上继续训练），只是数据不同
- **个人只学企业微调一步**：指令版 + 领域数据 + SFT/LoRA（工具 LLaMA-Factory / swift），厂商那步下载现成的即可
- 两处常见误读：推理 ≠ Agent（推理是模型一次前向计算，Agent 是多次调用推理的上层编排）；部署 ≠ vLLM（vLLM 是引擎之一，部署还包括量化、资源规划、协议暴露）

## 2 学习内容

1. **推理基础**（Mac 16GB 现在就能做）：采样参数实验、思考开关对比、system 提示词、多轮对话
2. **Tokenizer 原理**：BPE 分词、token id、聊天模板怎么拼
3. **API 调用**：百炼 / Qwen 官方 API，有 key 就能练
4. **Agent / 工具调用**：function calling（Qwen3 强化过 Agent 能力）
5. **微调**（台式机 5060 Ti 16G）：企业微调——指令版 + 领域数据，LoRA / QLoRA 微调 8B，SFT 数据构造，工具 LLaMA-Factory / swift
6. **部署服务化**（台式机）：vLLM / SGLang 起 OpenAI 兼容接口；量化 GGUF / AWQ / GPTQ
7. **架构原理**：思考/非思考双模式、MoE（30B-A3B：总 30B 只激活 3B）、256k 上下文（Qwen3-Next）
8. **多模态**：Qwen3-VL 看图理解

## 3 建议顺序

① Mac 上改采样参数 + 思考开关 + 多轮对话 → ② 学 tokenizer / 模板原理 → ③ 台式机 vLLM 部署 8B → ④ LoRA 微调 → ⑤ 评测验证（benchmark / 领域测试集对比微调前后） → ⑥ Agent 工具调用。
