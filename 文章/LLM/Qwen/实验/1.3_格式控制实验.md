# 格式控制实验

配套 [输出格式控制](../1.5_输出格式控制.md)。两个实验：先纯 Python 模拟掩码机制（0 依赖），再用 outlines 跑真实约束解码。

## 实验 A：模拟掩码机制（0 依赖，5 分钟）

复现约束解码的核心一步——状态机把非法 token 的分数清零：

```python
import math
import random

logits = {'"': 1.8, '}': 0.5, '我': 3.2}   # 模型给 3 个候选的打分
legal = {'"', '}'}                          # 状态机：刚写完 { 只许 " 和 }

# 1. 屏蔽：非法候选分数 → -inf
logits = {t: (s if t in legal else float('-inf')) for t, s in logits.items()}

# 2. softmax：-inf 的概率 = 0
probs = {t: math.exp(s) for t, s in logits.items()}
total = sum(probs.values())
probs = {t: round(p / total, 3) for t, p in probs.items()}
print(probs)   # {'"': 0.786, '}': 0.214, '我': 0.0}

# 3. 挑：贪心取最高分；采样按 probs 抽
greedy = max(probs, key=probs.get)
sample = random.choices(list(probs), weights=list(probs.values()))[0]
print("贪心:", greedy, " 采样:", sample)
```

观察点：

- 「我」分数 3.2 最高但被清零——模型想写「我」，状态机不让，只能在 `"` 和 `}` 里挑
- 屏蔽后概率重新归一化：`"` 0.786 + `}` 0.214 = 1
- 把 `legal` 换成 `{'我'}` 再跑一遍，对比「约束决定一切」

## 实验 B：outlines 真实约束解码

llm 环境装 outlines：

```bash
~/Desktop/workSpace/envs/python/llm/bin/pip install outlines
```

跑 5 次约束生成：

```python
from outlines import models, generate
from pydantic import BaseModel

class Person(BaseModel):
    name: str
    age: int

model_o = models.Transformers(model, tokenizer)   # model / tokenizer 同 quick_start.py
generator = generate.json(model_o, Person)

for i in range(5):
    print(generator("输出一个 JSON：姓名张三，年龄 30"))
```

再跑 5 次不加约束的 model_generate（输出格式控制.md 第 1 节的代码），对比：

- 不加约束：偶尔输出非 JSON（多余解释、字段错乱、尾逗号）
- 加约束：5 次输出 100% 合法

注意：outlines 对 transformers 版本有兼容要求，装的时候看报错提示。
