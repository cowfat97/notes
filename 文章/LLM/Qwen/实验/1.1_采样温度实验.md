# 采样温度实验

配套 [Qwen3 参数汇总](../1.3_Qwen3%20参数汇总.md) 3.1 节。目的：直观感受 temperature 对输出的影响。

## 准备

模型加载同 quick_start.py（[快速上手](../1.2_Qwen3%20快速上手.md)），把生成逻辑包成函数方便改参数：

```python
def generate(prompt, temperature):
    messages = [{"role": "user", "content": prompt}]
    text = tokenizer.apply_chat_template(
        messages, tokenize=False,
        add_generation_prompt=True, enable_thinking=False)
    inputs = tokenizer([text], return_tensors="pt").to(model.device)
    out = model.generate(
        **inputs,
        max_new_tokens=512,
        do_sample=True,        # 必须开，否则贪心解码下 temperature 不生效
        temperature=temperature,
    )
    new_ids = out[0][len(inputs.input_ids[0]):]
    return tokenizer.decode(new_ids, skip_special_tokens=True)
```

## 实验步骤

1. 选一个有开放空间的问题，比如「用三句话介绍你自己」
2. 每个 temperature 各跑 2 遍：0.2 / 0.7 / 1.2，共 6 次
3. 记录输出，对比差异

## 预期

| temperature | 预期表现 |
| --- | --- |
| 0.2 | 两次输出几乎一样，保守固定 |
| 0.7 | 两次输出有差异，但都通顺自然 |
| 1.2 | 两次输出差异大，可能跑偏、重复 |

## 观察点

- 同一问题问 2 遍，输出差异随 temperature 变大
- 感受「随机性」和「质量」的取舍：越低越稳但死板，越高越活但易崩
