# 对话控制实验

三个小实验都在 messages 上做文章，模型加载同 quick_start.py（[快速上手](../1.2_Qwen3%20快速上手.md)）。

## 1 多轮对话：模型「记得」上文吗

```python
messages = [
    {"role": "user", "content": "我叫张三。"},
    {"role": "assistant", "content": "好的，张三。"},
    {"role": "user", "content": "我叫什么名字？"},
]
# 正常拼模板 + 生成，看模型能否答出名字
```

能答对不代表模型有记忆——对话历史被拼进了输入（「模型生成 = 续写」）。试试把第一轮删掉再问，模型就不知道了。上下文越长 token 越多，速度越慢。

## 2 思考开关：enable_thinking 对比

同一问题跑两遍，只改 `enable_thinking`（apply_chat_template 的参数）：

- `False`：直接给答案
- `True`：输出先有 `<think>...</think>` 思考过程，然后才是正文；用 151668 切两段（解析代码见 [快速上手](../1.2_Qwen3%20快速上手.md)）

观察：思考模式质量更好（Qwen3 官方推荐复杂任务开思考），但更慢、更长。想省时间就关掉。

## 3 system 人设：改语气

messages 最前面加：

```python
{"role": "system", "content": "你是毒舌评论员，说话尖刻但有趣"}
```

再问「评价一下今天的天气」，对比加 / 不加 system 的输出语气。

注意：system 必须放 messages 第一位，模型才把它当全局人设，而不是普通对话内容。
